# Startup Studio Starter Pack

## Best For

- founder-led product studios
- portfolios of related product bets
- venture-building environments
- mixed product, company, and operating-system repos

## Customize Early

Add to `CLAUDE.md` and `AGENTS.md`:
- which venture or product line the repo supports
- what is shared versus venture-specific
- operating priorities across product, GTM, and company-building work
- who the key stakeholders are
- what should always stay in local context instead of tracked docs

## Team Emphasis

Common recurring team and agent patterns:
- `Advisory Review Team`
- `Content & Publishing Team`
- `Git / GitHub Team`
- `Engineering Team`
- future company-building or executive-layer flows when they mature

## Local Context Suggestions

This pack benefits especially from `.claude/local-context/`.

Useful local-only notes often include:
- founder notes
- company strategy
- venture prioritization
- GTM and partnership context
- private operating assumptions across multiple initiatives

## Common Gotchas To Document

- which product or company layer a change belongs to
- what is reusable across ventures
- which docs are public-safe versus private-only
- when roadmap or company-building plans should stay local

## Cleanup Signal

Once the repo has a clear product/company identity, use `repo-cleanup` to remove kit leftovers that no longer match the actual operating model.
