# Design Pack Library

This directory holds the first reusable design-pack foundations.

These packs are meant to be:
- optional
- curated
- public-safe
- strong starting points for product, marketing, and brand-sensitive work

Current library:
- [`Clean SaaS Product`](clean-saas.md)
- [`Startup Studio / Founder Service`](startup-studio.md)
- [`Premium Service / Advisory`](premium-service.md)
- [`Technical Console / Dashboard`](technical-console.md)

The design-pack contract is defined in:
- [`docs/DESIGN_PACKS.md`](../DESIGN_PACKS.md)

Use these packs to start faster, then customize the real repo's brand, tokens, layout rules, and interface constraints in its own briefings or local context.
