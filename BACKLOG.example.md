# Backlog Template

Copy this file to `BACKLOG.md` for your local working backlog.

`BACKLOG.md` is intended to stay local and ignored so project-specific notes, machine paths, and private planning details do not end up in public git history.

## Status Guide

- `Proposed`: captured but not yet shaped
- `Planned`: understood well enough to execute later
- `In Progress`: actively being worked on
- `Blocked`: waiting on a dependency or decision
- `Done`: implemented
- `Dropped`: intentionally not pursuing

## Priority Guide

- `P0`: urgent or blocking
- `P1`: high-value next work
- `P2`: useful but not immediate
- `P3`: speculative or low-priority
