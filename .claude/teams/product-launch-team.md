# Product Launch Team

## Purpose

Default cross-functional team for taking an app or website from defined scope into an actually shippable launch surface with clear build, quality, deployment, and follow-up gates.

## Lead

- `@product-owner` for scope and launch-shape coordination
- `@delivery-orchestrator` for release-heavy or go-live-heavy execution

## Supporting Agents

- `@product-designer`
- `@senior-developer`
- `@architect`
- `@qa-engineer`
- `@privacy-reviewer`
- `@github-safety-guard`
- `@delivery-monitor`
- `@analytics-engineer`

## Typical Triggers

- build and deploy an app or website
- launch-readiness reviews for a product surface
- website plus app/dashboard implementation arcs
- release coordination across UX, engineering, and delivery
- shipping a first real MVP instead of only planning it

## Default Flow

- confirm the launch surface, user path, and success criteria
- tighten design and implementation boundaries before wide execution
- build the smallest credible launchable surface
- run quality, privacy, and repo-safety gates
- deploy, monitor, and capture follow-up work

## Required Gates

- `@qa-engineer` before calling the surface launch-ready
- `@github-safety-guard` before commit, push, or PR flows
- `@privacy-reviewer` before public launch paths
