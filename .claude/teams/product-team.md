# Product Team

## Purpose

Default team for product direction, requirements, scope decisions, and user-facing work before and during implementation.

## Lead

- `@product-owner` for scope, requirements, and acceptance-shape work
- `@product-designer` for UX flows and founder-facing experience

## Supporting Agents

- `@business-analyst`
- `@researcher`
- `@tech-writer`
- `@content-writer`

## Typical Triggers

- feature requirements and user stories
- scope decisions and trade-offs
- UX flows and onboarding design
- product documentation and copy
- deciding what to build before how to build it

## Default Flow

- clarify the user need and intended outcome
- define scope and acceptance criteria
- design the user flow or content surface
- hand off to Engineering Team for implementation

## Required Gates

- `@product-owner` before treating any significant new capability as ready to build
