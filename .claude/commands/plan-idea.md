# /plan-idea

## Purpose

Turn an idea into a validated execution plan rather than leaving it as vague discussion.

## Owned By

- Lead: `@idea-executor`
- Common support: `@devils-advocate`, `@judge`, `@architect`
- Orchestrator: `@master`

## What It Should Do

1. shape the idea into an execution plan
2. pressure-test tradeoffs and assumptions
3. recommend chat only, backlog only, or backlog plus linked plan
4. save the artifact only with approval

## Output

- execution plan
- artifact recommendation
