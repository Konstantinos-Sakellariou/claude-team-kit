# /log-feedback

## Purpose

Capture objective feedback when a workflow, result, prompt, command, or user interaction did not work as expected.

## Owned By

- Lead: `@feedback-analyst`
- Common support: `@customer-advocate`, `@workspace-updater`, `@backlog-updater`
- Orchestrator: `@master`

## What It Should Do

1. clarify what was expected
2. record what actually happened
3. classify the root cause objectively
4. write or update the local feedback artifact when warranted
5. recommend backlog follow-up only when the issue deserves real improvement work

## Output

- structured feedback entry
- root-cause classification
- corrective action recommendation
- optional backlog recommendation
